- Flexbox: навигационное меню (горизонтальное, адаптивное) и карточки (3–4 шт.) в
ряд.
- Grid: 
галерея/дашборд (2–3 колонки, 2–3 строки).
- Медиа-запросы для планшетов и мобильных; отсутствие горизонтальной прокрутки.
- Контрастность ≥ 4.5:1; семантически верные теги для карточек.
- Flex-карточки:
«Гипотезы исследования» (формулировка + статус). 
- Grid-дашборд: 
«Методы исследования» (метод, краткое описание, иконка – 3 блока). 
- Адаптивность: карточки – 1/2/3; Grid – 1/2/3
В семантике <details> + <summary> для раскрытия полного описания метода
